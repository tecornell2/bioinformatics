# EEMS

1. Convert a filtered .vcf file of SNPs (biallelic) to diff file
```sh
# Use PLINK to covert vcf to bed
plink --vcf Pegre-run5_demogr.vcf --make-bed --out Pegre-run5_demogr --allow-extra-chr

# convert the chromosome names to integers
# this changes all chromosome names to 0
awk '{$1="0";print $0}' Pegre-run5_demogr.bim > Pegre-run5_demogr.temp.bim ```
mv Pegre-run5_demogr.temp.bim Pegre-run5_demogr.bim
```
```sh
# run bed2diff in eems folder
/project/viper/venom/Taryn/bin/eems/bed2diffs/src/bed2diffs_v1 \
    --bfile /project/viper/venom/Taryn/Plestiodon/Pegregius/popgen/EEMS/data/Pegre-run5_demogr

# the output filename.diffs is use to run eems
```
2. Generate corresponding coordinate data for samples and species
- Sample coordinates (filename.coord)
    > Longitude, Latitude .tsv (no headers)
    > Must be in same sample_id order of .vcf file
- Habitat (species range) coordinates (filename.outer)
    > Longitude, Latitude .tsv (no headers)
    > Last coordinate must be the first coordinate in list (to close polygon)
    > Cannot be too complicated and/or be too close to sample coordinates (add 20% buffer).

To export the order of samples in the .vcf file:
bcftools query -l *.vcf > samples_list.txt
3. Create parameter file
```sh
# prefix of all files in /data/
datapath = ./data/Pegre-run5_demogr
# output file is generated by EEMS
mcmcpath = ./data/mcmcpath
# number of individuals in .vcf file and .coord file
nIndiv = 177
#SNP markers
nSites = 184654
# number of generated vertices within habitat bounds
# demes are clipped to these nodes
nDemes = 200
diploid = true
# lower iterations result in less resolution of landscape barriers
numMCMCIter = 2000000
numBurnIter = 1000000
numThinIter = 9999
```

4. Run EEMS
```sh
/project/viper/venom/Taryn/bin/eems/runeems_snps/src/runeems_snps --params Pegre-run5_demogr.ini
```
